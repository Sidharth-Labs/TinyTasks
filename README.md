# **TinyTasks**

*A simple task tracker built to learn the complete web development process.*

**Features**

* Add new tasks
* View tasks
* Mark tasks as completed
* Delete tasks



**Technologies Used**

* HTML
* CSS
* JavaScript
* Git and GitHub



**Project Status**

Devoloped.



**Purpose**

This project is a learning exercise to understand planning, designing, developing, testing, version control, and deploying a website.
